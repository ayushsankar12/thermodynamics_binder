  \item \textbf{Run Automated Mechanical \& Visual QA:}\newline
    \texttt{python qa/pdfcheck.py}\newline
    \texttt{python verify/verify\_all.py}
  \item \textbf{Mandatory Release Gates (\texttt{build/pdfcheck-report.md}):}
    \begin{itemize}
      \item \textbf{P1:} Exact US Letter ($612.0 \times 792.0\text{ pt}$) on every page.
      \item \textbf{P2:} Main/Gray $\le 280\text{ pp}$; QuickRef $== 12\text{ pp}$.
      \item \textbf{P3:} Zero unresolved cross-reference markers or leaked raw LaTeX macros.
      \item \textbf{P4:} Zero text spans in $0.72\text{ in}$ ($51.84\text{ pt}$) inner 3-hole punch margin.
      \item \textbf{P5--P6:} Footer \texttt{Page N of M} + \texttt{2026-11-22}; min font $\ge 5.0\text{ pt}$; $100\%$ embedded Type 1 fonts.
    \end{itemize}
\end{itemize}
\end{formulacard}
\nextcol[0.49]
\begin{formulacard}[Selective Duplex-Safe Page-Pair Replacement]
Because the binder uses \texttt{twoside} duplex margins ($0.75\text{ in}$ inner 3-hole punch margin, $0.50\text{ in}$ outer thumb-tab margin), \textbf{every physical sheet in the binder is an odd--even duplex leaf pair $(2k-1,\; 2k)$}:
\begin{enumerate}
  \item \textbf{Page-Count-Neutral Edits:} Keep edits inside a chapter's final \texttt{\textbackslash clearpage} (or inside a 1-page \texttt{quicksheet}) so downstream page numbers do not shift.
  \item \textbf{Identify Physical Leaf Pair $(2k-1,\; 2k)$:}
    \begin{itemize}
      \item Edited \textbf{odd page $p=2k-1$} (front/recto) $\Rightarrow$ reprint pages \textbf{$p$ to $p+1$}.
      \item Edited \textbf{even page $p=2k$} (back/verso) $\Rightarrow$ reprint pages \textbf{$p-1$ to $p$}.
    \end{itemize}
  \item \textbf{Print Settings:} Select \textbf{Actual Size / 100\%} (never ``Fit to Printable Area''), \textbf{Two-Sided: Flip on Long Edge}, punch on the $0.75\text{ in}$ inner margin, and swap the single leaf into the 3-ring binder.
\end{enumerate}
\end{formulacard}
